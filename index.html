Xposed 增强模块

WhiteShell 是一个运行在 Xposed 框架下的游戏内增强模块。挂载后直接在游戏界面内呼出控制台，功能模块独立开关、热加载，不动原始安装包。

挂在框架层，改在运行时

不修改安装包本体，全部逻辑通过 Xposed 在进程内注入。装一次，跟着版本走。

🧷

Xposed 框架挂载

基于 LSPosed / EdXposed 的 Hook 入口，进程启动即加载，无需重签游戏包，原包随时可卸载重装。

🎛️

游戏内控制台

ImGui 即时渲染面板，绑定悬浮按钮，游戏里随时呼出。开关、滑条、数值输入全部可拖拽调整，不切后台。

🧩

模块化功能开关

每个功能独立编译成子模块，控制台里单独启用或关闭。关掉的模块不占渲染资源，也不挂对应 Hook 点。

🔄

版本快速跟进

游戏小版本更新后重新定位偏移，模块侧热更新配置。大版本改动走发版，跟进周期控制在数日内。

🧠

内存读写与偏移管理

集中管理偏移表，按游戏版本分组存储。新版本只补偏移表，不改业务代码，降低出错面。

💾

配置导入导出

整套参数一键导出为 JSON，换设备或重装直接导入还原。支持多套配置分别保存、快速切换。

常见问题

需要什么运行环境？

Android 8.0 及以上，设备已 Root，框架侧安装 LSPosed 或 EdXposed。游戏本体为我的世界中国版，模块只对勾选了作用域的进程生效。

怎么安装？

装 APK → 打开框架管理 → 模块列表里启用 WhiteShell → 在作用域里勾选我的世界中国版 → 强制停止游戏进程后重新启动。进游戏看到悬浮按钮即挂载成功。

支持哪些游戏版本？

当前 v2.4.0 适配中国版 1.20 内核版本。旧内核版本偏移表仍在包里，可在控制台的版本页手动切换。新版本发布后偏移表单独热更。

游戏更新后失效怎么办？

先检查控制台版本页有没有推送新偏移表，有就直接更新，重启游戏即可。没有推送说明是内核结构改动，等发版。偏移表位置在 config/offsets/，可手动替换。

配置怎么备份？

控制台设置页里有导出按钮，生成一个 JSON 文件，默认落在 WhiteShell/config/。导入时选同一文件即可还原，多套配置分开命名保存。
